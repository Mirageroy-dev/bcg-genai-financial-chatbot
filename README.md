# BCG X GenAI – Financial Analysis Chatbot

A financial data analysis and rule-based chatbot project developed as part of the **BCG X GenAI Job Simulation** on Forage.

The project analyzes financial data for **Microsoft, Apple, and Tesla** and provides simple, easy-to-understand financial insights through a predefined-query chatbot.

## 🎯 Project Objective

The objective of this project is to:

- Analyze financial data for Microsoft, Apple, and Tesla
- Calculate key financial metrics
- Compare companies based on financial performance
- Identify year-over-year changes
- Build a simple rule-based financial chatbot
- Provide clear financial insights using natural-language queries

## 🛠️ Technologies Used

- Python
- Pandas
- Jupyter Notebook
- CSV datasets
- Rule-based natural-language query matching

## 📊 Financial Metrics

The project works with the following financial metrics:

- Total Revenue
- Net Income
- Net Profit Margin
- Total Assets
- Total Liabilities
- Cash Flow from Operating Activities

The **Net Profit Margin** is calculated using:

`Net Profit Margin = (Net Income / Total Revenue) × 100`

## 🏢 Companies Covered

- Microsoft
- Apple
- Tesla

The provided datasets contain financial information for **2023–2025**.

## 🤖 Financial Analysis Chatbot

The chatbot retrieves information from the provided CSV datasets and responds to predefined financial questions.
